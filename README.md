# Social Post

Independent social publishing and scheduling application.

This **Fresh Setup** build is intentionally empty: no Loomic database content, sessions, social tokens, media, or secrets are included.

Start with `FRESH-SETUP.md`.

Main features retained from the Social Post codebase include workspace/team/client management, account connection, Composer, image/Reel/Story/Carousel publishing, Publish Now, scheduling, queue, calendar, Story editor, Finish in Instagram workflow, Supabase Storage uploads, and platform integrations supported by the codebase.
